# 设计语言

客户端有四套设计语言，共用同一份渲染代码，差别来自 `Palette` 里的"姿态 token"
（圆角、描边、内距、标题字号、等宽、全大写、横线、投影、内阴影、页面底色）。
切换按钮在标题栏（`Layers` 图标），选择写入 `gui-theme.json` 的 `style` 字段。

| 风格 | 定位 | 圆角 | 内距 | 标题 | 装饰 |
|---|---|---|---|---|---|
| **Studio** | 默认外观，半透明面板叠在毛玻璃上 | 6 | 12 | 15px | 无 |
| **极简 Minimal** | 少元素、大留白、单一强调色、一个超大标题 | 10 | 20 | **30px** | 无 |
| **粗野 Brutal** | 浏览器默认材料、暴露结构、零装饰 | 0 | 10 | 16px 等宽全大写 | 只有 1px 实线 |
| **拟物 Skeuo** | 可命名的真实材质 + 统一光照 | 9 | 14 | 15px | 渐变 + 投影 + 内阴影 |

## 极简（Minimalism）

**约束的是内容与布局，不是渲染。**

- **元素最少化**：一块导航（左侧 Sidebar）、一条消息（底部 Status Bar）、一组主操作
  （标题栏 Toolbar）。装饰元素为零——没有分割装饰线（`line` 透明度降到 5%）、没有投影。
- **负空间**：内距 20px（Studio 的 1.7 倍），卡片与面板都靠空间分组而不是靠边框。
- **有限调色板**：近单色（深色 `#0a0a0b`→`#e6e6e6`，浅色 `#fbfbfa`→`#2f2f33`）
  加**一个**强调色；强调色只出现在"选中的那一个"上（选中行、选中卡片、焦点环）。
- **一个戏剧性排版时刻**：标题栏品牌字号 30px，是屏幕上最响的东西；其余文字保持
  10–13px，形成明确层级。
- **Rendering 灵活**：这里选平涂（无投影无渐变），因为大留白已经承担了层次。
- **可发现性不牺牲**：五个工具动作全部留在标题栏可见位置，没有为了"空"把它们塞进
  图标菜单深处；文字对比度沿用调色板（深色底 `#e6` 对 `#0a` 约 13:1，浅色底
  `#2f` 对 `#fb` 约 11:1，都高于 4.5:1）。
- **没有滑向 flat design 的陷阱**：flat 是"渲染方式"，极简是"内容与布局"；这里的
  极简没有靠再塞内容显得丰富，所以保持成立。

## 粗野（Web Brutalism）

**默认材料即设计。**

- **浏览器默认材料**：等宽字体（Menlo）承载标题与分区标签，标签全大写；强调色退场，
  链接保留"可点"的蓝色（`#0000ee`），与正文形成真实的链接暗示。
- **暴露文档结构**：横线（`rules` token）在侧栏行、卡片、面板、状态栏之间全部可见；
  分区分割用 1px 实线而不是留白。
- **零装饰渲染**：圆角 0、无投影、无渐变；`linear_gradient` 退化为首尾同色。
- **utility-first 密度**：内距 10px，行高更紧，目的是"一屏读更多"而不是"看起来高级"。
- **没有滑向 neobrutalism**：没有饱和色块、没有粗描边造型、没有位移阴影——那些是
  图形化戏服；这里的"粗"来自不做修饰，不是来自另加修饰。
- **可读性与可达性**：正文 11–13px 不变小；焦点环用蓝色（`#0000ee`）保持可见；
  链接保持下划线式强调语义（`link` 色用于"复制/显示"这类动作）。

## 拟物（Skeuomorphism）

**模拟可命名的真实材质，并统一光照。**

- **材质**：浅色是**纸张与桌面**（页面 `#cbc1ac → #b8ac94` 的桌面渐变，卡片
  `#fdf8ec` 的纸面，侧栏 `#efe7d6` 的牛皮纸）；深色是**石墨金属**（页面
  `#262a2d → #191b1d`，卡片 `#33373b`，描边 `#141618` 的暗缝）。
- **统一光照模型**：光自上而下——凸起元素（卡片）投**向下**阴影；凹陷字段（详情分区、
  输入区）用 **inset 内阴影**。两者方向一致，不混用。
- **真实物件隐喻**：整个右栏是"一叠纸张卡片"（Inspector），每个分区是一张凹下的表单卡；
  状态栏是一条压印的横条。
- **分层渐变**：页面与侧栏用两层渐变制造纵深；卡片用平涂 + 投影（纸张本身不渐变）。
- **对比度**：纸面上正文 `#3b3225` 对 `#fdf8ec` 约 11:1；石墨上 `#d6dade` 对 `#33373b`
  约 8:1。纹理只通过颜色层次表达，不叠噪声图，避免把文字压进纹理里。
- **没有滑向 neumorphism**：neumorphism 是"同一种柔挤出表面"；这里有可命名的材质
  差异（纸 vs 桌面 vs 金属暗缝），并且角落、描边、阴影颜色都不同。

## 组件姿态（对照 namethatui 的命名标准）

只借用**姿态与命名**，不引入任何外部组件。

| 我们的控件 | 标准名字 | 姿态要点 |
|---|---|---|
| 左侧 agent 列 | **Sidebar / Source List** | 行内：图标 + 名称 + 尾部计数；选中行整行高亮 |
| 顶部一行 | **Toolbar（Unified Title Bar）** | 品牌 + 一组图标动作，动作全部可见 |
| 搜索框 | **Search Field** | 前置放大镜、占位提示、⌘K 聚焦 |
| 全部/已入库/仅目录 | **Segmented Control** | 一排段，**当前段可见选中**，不是三个独立按钮 |
| 卡片/列表切换 | **Segmented Control（2 段）** | 与上面同一套视觉与高度 |
| 中间技能墙 | **Card** | 媒体（首字母/封面）+ 标题 + 正文摘要 + 页脚元信息 |
| 右侧详情 | **Inspector** | 分区卡片；可关闭（✕ / Esc / 再点同卡） |
| 已入库 / 仅目录 | **Badge** | 不可点击的紧凑标签，不是按钮 |
| 归属点阵 | **Status Dot** | 每 agent 一色点，hover 显示名字 |
| 空状态 | **Empty State** | 标题 + 一行"下一步做什么"的引导 |
| 底部一行 | **Status Bar** | 只读信息 + 快捷键提示 |
| 面板之间的线 | **Separator**（1px） | 粗野风格下全量出现，其余风格淡到几乎不可见 |
| 焦点 | **Focus Ring** | 与强调色同色，选中卡片用描边而非阴影表达 |
| ⌘K / `/` | **Search Field 聚焦快捷键** | 聚焦搜索框（不是独立浮层），输入即过滤 |

## 切换与持久化

```
标题栏 Layers 图标 → 循环 Studio → 极简 → 粗野 → 拟物
~/.skillctl/gui-theme.json  {"dark":true,"accent":0,"style":"Minimal"}
```

`style` 缺省为 `Studio`（老配置文件没有该字段时按默认处理）。深/浅与强调色仍独立可调，
三套设计语言在深色与浅色下都有完整配色。
